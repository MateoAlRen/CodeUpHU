# 🎓 Academic Grade Management System

A complete system for managing **teachers, students, and grades**, built with **Spring Boot, Java 21, Maven, JPA, Hibernate, and MySQL**.

---

## 📖 Description

This project allows you to:

- Register and manage **teachers**  
- Register and manage **students**  
- Record, update, and view **student grades**  
- Manage relationships between teachers and classes, and between students and their grades  

Ideal for educational environments that need a **centralized and efficient academic management system**.

---

## ⚡ Key Features

- 👨‍🏫 Teacher management  
- 🧑‍🎓 Student management  
- 📝 Grade management  
- 🔗 Relationships between teachers, students, and grades  
- 💾 Data persistence with **MySQL**  
- ⚡ REST API for CRUD operations

## 💻 Installation

Follow these steps to run the project locally:

```bash
# Clone the repository
git clone https://github.com/MateoAlRen/CodeUpHU.git

# Enter the project directory
cd academic-system

# Build the project with Maven
mvn clean install

# Run the application
mvn spring-boot:run
